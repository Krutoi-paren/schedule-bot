# Бот графика поваров (Telegram)

Telegram-бот для составления расписания поваров, учёта часов и зарплаты.

## Что умеет

- **Основной повар** — каждый день 11:00–00:00, ставка **230 ₽/час**
- **Второй повар** — пт–вс 16:00–00:00, ставка **170 ₽/час**
- Сбор сообщений о доступности (любой текст сохраняется)
- Структурированный ввод доступности (пн 12-18 и т.д.)
- Автоматическое формирование графика на 2 недели
- Ручное назначение / редактирование смен
- Расчёт зарплаты за период (3–17 и 18–2 число)
- Добавление премий
- Админ-панель только для указанных username

## Деплой на Railway

1. Создай новый проект на [railway.app](https://railway.app)
2. Deploy from GitHub (или CLI)
3. Добавь переменные окружения:
   - `BOT_TOKEN`
   - `ADMIN_USERNAMES`
   - `TIMEZONE=Europe/Moscow`
4. Start Command: `python main.py`
5. Railway сам поставит зависимости из `requirements.txt`

База `schedule.db` будет храниться в файловой системе сервиса.  
Для постоянного хранения можно подключить Volume.

## Деплой на Bothost

1. Загрузи файлы проекта
2. Укажи `BOT_TOKEN` и остальные переменные в настройках
3. Команда запуска: `python main.py`
4. Python 3.11+

## Как пользоваться

1. Админ пишет `/start` → видит полное меню
2. **Добавить работника** — имя + @username
3. Люди (или админы) скидывают текстом, когда могут выйти → сообщения сохраняются
4. Можно добавить структурированную доступность через кнопку
5. **Сформировать график** — бот пытается распределить людей по слотам
6. **Ручное редактирование** — назначить конкретного человека на дату и роль
7. **Зарплата за период** — часы, роли, премии
8. **Добавить премию** — сумма + комментарий

## Структура БД

- `workers` — сотрудники
- `availability` — структурированная доступность
- `availability_messages` — сырые сообщения
- `shifts` — смены (авто + ручные)
- `bonuses` — премии

## Команды

| Команда | Описание |
|---------|----------|
| `/start` | Главное меню |
| `/id`    | Узнать свой Telegram ID |
| `/help`  | Справка |

## Замечания

- Авто-распределение сейчас простое (берёт первого подходящего по дню).  
  Ручное редактирование всегда в приоритете.
- Чтобы работник видел «свою» зарплату — добавь его с точным `@username`.
- Токен в коде/истории чата нужно сменить.
